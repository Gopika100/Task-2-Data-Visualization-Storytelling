# Task 2: Data Visualization and Storytelling

## Superstore Sales Analysis

This project analyzes a Superstore sales dataset to identify
important sales and business patterns using data visualization.

## Objective

The objective of this project is to create meaningful visualizations
and communicate business insights through charts and graphs.

## Tools Used

- Python
- Pandas
- Matplotlib
- Google Colab

## Dataset

Superstore sales dataset obtained from Kaggle.

## Visualizations

The project includes:

1. Sales by Product Category
2. Sales by Region
3. Profit by Product Category
4. Sales by Sub-Category
5. Sales by Shipping Mode
6. Discount vs Profit

## Key Insights

The analysis examines:

- Category-level sales performance
- Regional sales performance
- Product profitability
- Sub-category sales
- Shipping-mode sales patterns
- Relationship between discount and profit

## Conclusion

Data visualization helps transform raw sales data into meaningful
business insights. The project demonstrates how different charts
can be used to understand sales, profit, products, regions,
shipping methods, and discount patterns.
